# وكيل الذكاء الاصطناعي

مشروع بداية لوكيل ذكاء اصطناعي، وجميع الملفات موجودة في المجلد الرئيسي بدون مجلدات داخلية.

## الملفات
- index.html: واجهة التطبيق
- style.css: التصميم
- script.js: إدارة المحادثة
- agent.js: نقطة ربط الوكيل بنموذج الذكاء الاصطناعي
- config.js: إعدادات عامة
- package.json: إعداد المشروع

## الخطوة التالية
هذه النسخة لا تحتوي على مفتاح API ولا ترسل بيانات إلى خدمة خارجية. الخطوة التالية هي إضافة خادم آمن وربط الوكيل بنموذج ذكاء اصطناعي حقيقي دون كشف المفتاح في المتصفح.
